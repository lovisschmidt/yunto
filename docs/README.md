# Docs

| Doc                                                    | What it's for                                                                                                                                       |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| [specs/](./specs/)                                     | Implementation specs — point-in-time, ADR-style snapshots of _why_ each feature was built the way it was. See [specs/README.md](./specs/README.md). |

For _how the app behaves today_, read the code, the root [README](../README.md), and
[CLAUDE.md](../CLAUDE.md). The specs here are snapshots and are not edited to track later
changes — a newer spec supersedes the relevant parts.
